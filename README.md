## O que já entreguei

- 🔌 **6 integrações** com marketplaces e sistemas externos, incluindo um grande ERP, em um hub integrador de marketplace
- ⚡ Importação de anúncios bem mais rápida: cada página vira uma mensagem no **Kafka**, processada em paralelo com **threads virtuais**, com retentativa e tratamento de erro por anúncio
- 🧾 Padrão **Outbox** para não haver inconsistência entre banco e mensageria; agendamento de tarefas com **Redis**
- 📦 Funcionalidade de **cobertura de estoque em dias**, do levantamento de dados à implementação
- 🧮 Ajustes na emissão de notas fiscais para a **Reforma Tributária** e lançamento de notas fiscais de entrada
- 🤖 **IA aplicada**: skills e conexões entre assistentes de IA (LLMs, MCP), Grafana e métricas para investigar problemas com mais contexto
